# Créditos e fontes de metadata

O `tg-upload` consulta serviços externos apenas para montar apresentações opcionais de mídia.

- **AniList**: usado para metadata de animes por meio da API GraphQL pública.
- **TMDB (The Movie Database)**: usado para metadata de filmes, séries e desenhos. A credencial do TMDB é fornecida pelo próprio usuário e fica somente na configuração local (`%USERPROFILE%\.telegram-media-upload\config.json`) ou em variável de ambiente.

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB: https://www.themoviedb.org/
AniList: https://anilist.co/
